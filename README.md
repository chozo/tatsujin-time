# 達人の時間

**遊ぶ：https://game.chozo.net/tatsujin-time/**

挑戦を重ねるほど、時がゆっくり流れるように見えてくる3Dのブラウザゲーム。頭上から落ちてくる果物・紙風船・栗・薪を、指（PCではマウスのドラッグ）でなぞってすべて斬る。

1回目は現実の速さ（5秒）。斬りきれなくても、次の挑戦では2倍、その次は3倍…と時が遅く見えるようになり、10回目以降は10倍（体感50秒）になる。斬り終えるたびに、現実の速さのリプレイ（5秒）で自分の剣さばきを見る。全部斬ると次のステージが開く（全5ステージ）。

失敗しても、挑戦したこと自体が修行になって実力が上がっていく、ということを伝えるゲーム。スマホの縦画面を優先し、PCでも遊べる。

## 遊び方

1. タイトルでステージを選び、「開始」を押す。始めに「ステージ1／1回目」と出て、プレイが始まる。
2. 頭上から落ちてくるものを、指でなぞって斬る。ゆっくりなぞった線では斬れない。斬った破片はさらに斬れる（小さくなりすぎると斬れない）が、数には入らない。
3. 5秒（遅く見えるときは体感でその倍数の秒数）で終わり、「リプレイ（実際の時間）」で同じ場面を現実の速さで1回見せる。
4. 結果画面に、斬った数（「12個　全20個中」）と、遅さごとの最高記録を出す。
   - 全部斬れなかったとき：「再挑戦（2倍遅く見える）」で、次は1倍ずつ遅く見える（10倍まで）。案内は「この挑戦が力になった。次は、時が2倍遅く見える。」
   - 全部斬ったとき：次のステージが開き、「ステージ2へ進む」で次のステージの1回目（現実の速さ）から挑戦する。
   - ステージ5を全部斬ったとき：紙吹雪が舞い、「すべてのステージクリア、おめでとう！／あなたは達人の時間の流れを体得しました。」と出る。
5. 回数・最高記録・開いたステージはブラウザに保存する。「最初からやり直す」で記録を消せる。

プレイ中は、画面上部に体感の残り秒数・斬った数・現実の経過秒数を出し、その下に今のステージと遅さ（「ステージ1（4倍遅い）」など）を出す。

## ステージ

ステージが上がるごとに、落ちてくる数が増え、速くなり、見て判断する仕掛けが1つずつ増える（前のステージの仕掛けも残る）。新しいものが混ざるステージを初めて遊ぶときは、「開始」の前に説明の画面を出す（2回目からは出さない）。

| ステージ | 数 | 内訳 | 説明の画面・タイトルの一言 |
|---|---|---|---|
| 1 | 20 | 果物 20 | — |
| 2 | 30 | 果物 27、紙風船 3 | 紙風船：ふわりとゆっくり落ちてくる |
| 3 | 40 | 果物 32、紙風船 3、栗 5 | 栗：小さく、勢いよく速く落ちてくる |
| 4 | 55 | 果物 42、紙風船 3、栗 5、薪 5 | 薪は縦にしか斬れない（縦に斬れば割れ、横に振ると弾かれる絵つき） |
| 5 | 75 | 果物 50、紙風船 5、栗 10、薪 10 | 最後の試練：これまでのすべての経験を、このステージにかけろ |

- 果物はりんご・みかん・梨・柿・桃。画面の上の外から出て、左右に散らして落とす。重力は実際と同じ 9.8m/s²。ステージ1は現実の速さで約1.2〜1.35秒で画面の下へ抜け、後のステージほど勢いをつけて速く落とす。ステージ5は最短約0.65秒。
- 後のステージほど、2つ・3つまとめて落ちてくることが増え、4〜6個が横一列に落ちてくる「一斉」も入る。
- 薪は回らず立てたまま落ちる。縦に振ると割れ、横に振ると刀が弾かれて火花と「カキン」という音が出る（同じ一振りでは一度だけ）。
- 落としても減らない。出てきたものを全部斬れば、そのステージを極めたことになる。
- 配置は毎回同じなので、練習すると上達する。

数と内訳は `src/stage.ts` の `DANS`（`count` が合計、`mix` が混ぜるものの個数、`note` がタイトルの一言、`intro` が説明の画面）。合計がちょうど `count` になるよう、出る間隔の倍率を1から0.002ずつずらして探す（今はステージ1で約0.89倍、ステージ2で約0.82倍、ステージ3で約0.84倍、ステージ4・5はほぼ1倍）。

## 画面の文言の方針

- 「修行」という言葉は使わず「挑戦」と書く（「挑戦 1回目」「再挑戦」）。挑戦すること自体が修行になり、失敗しても次は時が遅く見える、ということを伝えるため。
- 数は漢数字を使わず算用数字で書く（「1回目」「2倍遅く見える」）。
- 点数は使わず、斬った数を「◯個」で出す。

トップには、ゲームの説明文を出す（`index.html` の `.lead`）。文字を読みやすくするため、タイトル画面だけ背景を暗くしている。

## 試作の別モード

作る途中で試した遊び方とステージも残している（URL で開ける。記録はステージごとに別に保存する）。

| 開き方 | 内容 |
|---|---|
| `?flow=pair` | 常人の目（現実の速さで5秒）→ 達人の目（5倍遅い体感25秒）の2回で1組 |
| `?stage=missiles` | 奥から手裏剣・礫・矢がこちらへ飛んでくる。斬れずに手前まで来ると「被弾」で −1点。まだ間合いの外の遠くで斬ることになり不自然なので、果物に切り替えた |
| `?stage=leaves` | 夕暮れに舞い落ちる紅葉・楓・イチョウの葉を斬る（最初の試作） |

既定は `src/config.ts` の `DEFAULT_FLOW`（`'training'`）と `DEFAULT_STAGE`（`'fruits'`）。

## 仕組み

| 項目 | 内容 |
|---|---|
| 時間 | ゲーム内の時間を、挑戦の回数に応じて実時間の 1/1〜1/10 の速さで進める。物理は 1/600 秒の固定刻み |
| 斬る判定 | 指の線分が物体の投影円を通ったら斬る。切断面は「カメラ位置と線分の両端を通る平面」 |
| 切断 | メッシュを平面で分割し、切り口をつながった部分ごとに塞ぐ（`src/slicer.ts`） |
| 破片 | 斬ってから体感1秒後に、1秒かけて透明になって消える。薄くなり始めた破片は斬れない |
| リプレイ | 全破片の位置と向きを毎ステップ記録し、時刻で補間して再生する |
| 音 | Web Audio で合成。斬る音は「風切り・刃が入る音・手応え」の3層。時間が遅いほど低く長くする（`stretch()`）。リプレイでは斬った時刻に予約して鳴らす |
| 紙吹雪 | `src/main.ts` の `createConfetti`。左右の下から打ち上げ、上から約3秒降らせて、落ちきったら止める（太鼓の音つき） |

## 調整値

`src/config.ts` にまとめている。主なもの：

- `maxSlow`：いちばん遅くなったときの遅さ（10倍）
- `worldDuration`：1回のプレイの長さ（ゲーム内5秒）
- `fruit`：重力・出てくる高さ・落ちる範囲の横幅
- `minSwipeSpeed`：剣筋として扱う最低の指の速さ
- `minPieceSize`：これより小さい破片は斬れない
- `cutFade`：破片が消え始めるまでと、消えるまでの時間
- `trailLife`：剣筋の残像の長さ

## 開発

```sh
npm install
npm run dev      # http://localhost:5173/（同じネットワークのスマホからも開ける）
npm test         # 単体テスト（切断で体積が保たれるか、挑戦の記録、ステージごとの数と内訳など。28件）
npm run build    # dist/ を空にしてから dist/tatsujin-time/ に出力
npm run deploy   # ビルドして Cloudflare Workers に公開
npm run ogp      # OGP画像（public/ogp.png）を書き出す
npm run promo    # 告知動画を作る（下の「告知動画」）
```

ブラウザでの確認（開発サーバーを起動した状態で。`/Applications/Google Chrome.app` をヘッドレスで使う。URL を引数に渡せば公開中のサイトも確かめられる）：

- `node tools/e2e-training.mjs`：挑戦の流れ。11回続けて遊び、遅さが1→10倍に変わること、斬った数が正しいこと、破片では数が増えないこと、プレイ中の「ステージ1（◯倍遅い）」とリプレイの表示、最高記録、再読み込み後も回数が残ること、全部斬るとステージ2の説明が出て次へ進めること、やり直し、360×640 で結果画面が収まること
- `node tools/check-rules.mjs`：薪を横に振ると弾かれ縦に振ると割れること、落としても減らないこと
- `node tools/e2e.mjs`：試作の `?flow=pair` の流れ
- `node tools/check-same.mjs`：常人の目と達人の目で、同じものが全刻みで同じ位置にあること
- `node tools/check-rise.mjs`：画面の下半分で上へ動くもの（跳ね返って見えるもの）がないこと
- `node tools/render-sfx.mjs tools/sfx`：斬る音の聞き比べ用 WAV を書き出す

## 告知動画

縦型 1080×1920・約31秒の告知動画を、実際のゲーム画面を1コマずつ撮って作る（promo-video スキルの道具。`tools/promo/`）。

```sh
npm run promo                                     # BGM を作り、ビルドして全コマを撮影し、MP4 に書き出す（約1分）
PROMO_EVERY=15 node tools/promo/record.mjs        # 15コマおきの確認用の一覧だけ作る（構成の確認。先に npm run build）
PROMO_ENCODE_ONLY=1 node tools/promo/record.mjs   # 撮り直さずに音と書き出しだけやり直す
```

出力はアプリの隣の `../video/`（リポジトリには含めない）：`tatsujin-time-promo.mp4`、表紙 `tatsujin-time-promo-cover.jpg`、2秒おきの一覧 `tatsujin-time-promo-sheet.jpg`。途中ファイルは `../video/work/`。

構成（台本は `tools/promo/scenario.js`）：

1. 「頭上から落ちてくる果物を、すべて斬れ！」：ステージ1の1回目（現実の速さ）。空振りばかりで1個だけ斬る（「1個しか斬れない…」）
2. 「すべて斬れなければ再挑戦！」：結果画面（1個／全20個中、「再挑戦（2倍遅く見える）」）
3. 「さっきの挑戦で腕が上がり、ゆっくり見える！」：2回目（2倍遅く）。さっきより斬れる
4. 「挑戦を重ねるごとにゆっくり見える！」「5回目は5倍遅く、これなら全部斬れる！」：次々に斬る
5. 「本来の速さで見ると…」：リプレイ（現実の速さ）で全部斬る → 「すべて斬った！」（20個）
6. 「ステージが上がるごとに難しくなる」：ステージ2（紙風船）・3（栗）・4（薪は縦にしか斬れない）・5（すべての経験をかけろ）のプレイ画面
7. エンドカード：ゲームの紹介と公開URL

- 斬る気持ちよさはゲームの中の斬る場面だけで伝える。効果文字・フラッシュ・ズーム・画面の揺れは入れない。
- 斬る操作は台本の中の自動の剣（下にあるものから斬る。1回目は少し上を振って空振りさせる）。見せない区間は `__game` を直接進めて全部斬る。
- BGM は静かな曲を `tools/promo/make-bgm.mjs` でコードから作る（`tools/promo/bgm.wav`。作り直せるのでリポジトリには含めない）。打楽器は入れず、ゆっくり膨らんで消えるやわらかい和音（Dmaj7 → Bm7 → Gmaj7 → A6 をくり返し、最後は Dmaj9）と、ときどき鳴る小さな鈴のような高い音だけ。音源ファイルは使っていない。BGM は 0.6 倍の音量で混ぜる。
- 効果音はゲームの音をそのまま使う。全体の音量は、落ち着いた音にするため -17 LUFS（`config.loudness`。スキルの既定は -14）。
- 撮影用の入口として、`__game.audio.drain()` は予約された音（リプレイの斬る音）をゲーム内の時間がその時刻に来てから渡し、`state().targets` に未切断かどうか（`whole`）を入れている（`__game.audio.tune()` で撮影時の効果音を調整することもできるが、今の台本では使っていない）。遊び方は変えていない。`tools/promo/record.mjs` は、音量の目標を台本の `config.loudness` で変えられるようにした。

## 公開

Cloudflare Workers（静的アセット）で `https://game.chozo.net/tatsujin-time/` に公開している（Worker 名 `tatsujin-time`、ゾーン `chozo.net`）。`wrangler.jsonc` のルートは `game.chozo.net/tatsujin-time` と `game.chozo.net/tatsujin-time/*` だけで、workers.dev は使わない。ビルドの出力 `dist/tatsujin-time/` が URL の `/tatsujin-time/` に対応する。

```sh
npm run deploy   # = npm run build && wrangler deploy
```

ソースは https://github.com/chozo/tatsujin-time 。
